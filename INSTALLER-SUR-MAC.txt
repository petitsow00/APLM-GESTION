============================================================
  APLM BUZNESS COMPANY - INSTALLER SUR MAC
  (MacBook Air 13" Mid 2013, Intel, macOS Big Sur 11.7)
============================================================

Cette application est 100 % Python : legere, elle tourne bien sur ce Mac.
Sur Mac, on la lance depuis le code source (il n'y a pas de .exe Mac).

Suivez ces etapes simples, dans l'ordre.

------------------------------------------------------------
ETAPE 1 - INSTALLER PYTHON 3.12
------------------------------------------------------------
- Allez sur : https://www.python.org/downloads/
- Telechargez "Python 3.12" -> installeur "macOS 64-bit universal2"
  (compatible avec votre Mac Intel).
- Installez-le normalement (Continuer / Installer).

IMPORTANT : utilisez bien le Python de python.org (l'ancien Python du
systeme a une interface graphique trop vieille).

------------------------------------------------------------
ETAPE 2 - COPIER LE DOSSIER SUR LE MAC
------------------------------------------------------------
- Copiez le dossier "APLM_Voyages" sur le Mac (cle USB, AirDrop...).
- Placez-le par exemple sur le Bureau.
- Vous pouvez ignorer les dossiers "build" et "dist" (versions Windows).

------------------------------------------------------------
ETAPE 3 - LANCER L'APPLICATION
------------------------------------------------------------
- Ouvrez le dossier "APLM_Voyages".
- Double-cliquez sur "Lancer APLM.command".
  -> La 1re fois, il installe automatiquement les composants
     (1 a 2 minutes), puis ouvre l'application.

Si macOS bloque au 1er lancement ("developpeur non identifie") :
   clic droit sur "Lancer APLM.command" -> "Ouvrir" -> "Ouvrir".

(Si le double-clic ne fait rien : ouvrez le Terminal, tapez  chmod +x
 suivi d'un espace, glissez le fichier "Lancer APLM.command" dans la
 fenetre, Entree. Puis re-essayez le double-clic.)

------------------------------------------------------------
ETAPE 4 - SE CONNECTER
------------------------------------------------------------
Deux cas selon votre besoin :

  A) CE MAC REJOINT LE SERVEUR DU BUREAU (recommande)
     - Sur le PC SERVEUR : ouvrez Reglages reseau, notez l'adresse IP
       affichee ET la cle secrete affichee (generee automatiquement,
       propre a cette installation - plus surs qu'une cle identique pour
       tout le monde).
     - Sur ce Mac, a l'ecran de connexion, cliquez "Se connecter a un serveur".
     - Adresse IP du serveur : celle notee sur le PC serveur (ex : 192.168.1.77).
     - Cle secrete : remplacez la cle proposee par celle notee sur le PC serveur.
     - Cliquez "Tester" (doit devenir vert) puis "Enregistrer et se connecter".
     - Entrez votre identifiant et votre mot de passe.
     -> Le Mac voit alors LES MEMES donnees que les autres postes, y compris
        les coordonnees de l'agence et le logo (rien a ressaisir).

  B) CE MAC TRAVAILLE SEUL
     - Au 1er lancement, creez le compte administrateur, puis connectez-vous.

------------------------------------------------------------
DEUX FACONS D'UTILISER SUR MAC
------------------------------------------------------------
  1) SIMPLE (recommande) : double-clic sur "Lancer APLM.command".
     -> Installe tout seul et ouvre l'application.

  2) VRAIE APP DOUBLE-CLIQUABLE (equivalent de APLM_Setup) :
     double-clic sur "Construire APLM (Mac).command".
     -> Fabrique "APLM.app" et la copie sur le Bureau (a faire 1 seule fois).
        Ensuite, vous lancez le logiciel en double-cliquant sur APLM.app.
     (1er lancement de APLM.app : clic droit -> Ouvrir -> Ouvrir.)

------------------------------------------------------------
NOTES
------------------------------------------------------------
- Les PDF s'ouvrent automatiquement (via la commande "open" du Mac).
- Un vrai installateur .dmg se construit aussi sur le Mac (optionnel).
- Aucune fonctionnalite n'a ete supprimee ; ce sont les memes ecrans.
